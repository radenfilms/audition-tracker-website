Actor guide

20 August 2026 · Raden Films

How to organise self-tape auditions:Files, deadlines, and a workflow that sticks.

A strong take still fails if you cannot find the sides, miss the naming format, or upload the wrong file. Organising the tape is part of the job — not an afterthought once the camera is away.

This is about the system around the tape: where files live, how they are named, and the steps from brief to submit. For lighting, framing, and sound, use the self-tape tips checklist.

How actors usually do it

Talk to a few working actors and you will hear the same patterns — each fine until the week gets busy.

Camera Roll only. Fast on the day. Brutal a month later. Takes blur into each other, and “the good one” is buried under holiday photos.

Cloud folders by year or project. Common advice is a simple tree: year → project → role, with sides, slate notes, and the final MP4 in one place. Easy to search. Easy to abandon if every tape invents a new folder name.

Strict file naming. Casting often asks for something like Surname_Firstname_Role.mp4. When they do not, that same format is still the safe default. Some actors also keep an archive name with date and take: Smith_Jane_ROLE_2026-08-20_Take2.mp4.

A spreadsheet or notes app for the admin. Project, role, deadline, submitted yes/no. Works until you need the file next to the deadline, or a reminder on your lock screen.

One job record that holds everything. The brief, the sides, the finished tape, the status. That is the shape most actors are reaching for when Drive and Camera Roll stop keeping up.

A workflow that survives a busy week

Borrow the useful bits. Drop the theatre.

  1. Open a job the moment the brief lands. Before you storyboard the scene. Title, role, casting, due date, delivery method.
  2. Split the brief in two lists. Tech: frame, slate, takes, file name, format, size, where to upload. Creative: tone, character notes, relationships. Write them down once — do not trust a skim under pressure.
  3. Drop sides into that job’s folder (or attachment). One home for materials. Not “Downloads” forever.
  4. Prep and tape. Choices first, then light and frame. Keep the edit clean: slate if asked, scene, hard cuts. No music unless they want it.
  5. Name the export for casting. Their convention wins. Then save a copy into your archive with a date so you can find it again.
  6. Submit, then mark it submitted. Same day. Attach the file you actually sent. Update status when you hear back.

Three takes is usually enough: settle, commit, clean. Pick the alive one — not the one where the lamp is slightly nicer. Then stop picking at it and send before the window closes.

Folders and names that do not fight you

Pick one storage home and stick to it. A structure like this is enough:

  • Self-Tapes / 2026 / ProjectTitle_Role /
  • Inside: sides PDF, brief notes, SUBMIT_Surname_Firstname_Role.mp4, maybe a raw takes folder you can delete later

Rules that save headaches:

  • Casting’s file name is sacred. Match it character for character.
  • Default format when unspecified: MP4. Keep files lean when they ask for a size cap.
  • Do not leave the “final” only in Messages or email drafts.
  • Archive finished jobs by year so the live folder stays short.

  • One folder tree. One naming habit. No third “temporary” place.
  • Job exists before you roll camera.
  • Casting’s name on the upload. Your dated copy in the archive.
  • Tape file lives on the job record — not only in Camera Roll.

Quick answers

How should I name a self-tape file?

Exactly as casting asks. If they do not say, Surname_Firstname_Role.mp4 is the usual safe choice.

Do I need a fancy folder system?

No. Year → project → role is enough if you use it every time. Consistency beats a clever template you abandon.

Should the tape live in the app or in Drive?

Both can work. Attach the submitted file to the audition so it sits with the deadline. Keep a cloud archive if you want long-term storage and backups.

What if two tapes are due the same night?

Trust the calendar, not your inbox. Create both jobs when they land, set both dues, and knock them out in deadline order — not in the order the emails arrived.
